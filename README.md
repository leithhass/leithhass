### 👋 Salut, moi c'est Leith

Je conçois des **apps mobiles calmes, fluides et bien pensées** — pas juste fonctionnelles, mais agréables à utiliser. Mon terrain de jeu : **Flutter** pour le cross-platform, **Swift natif** quand iOS mérite le vrai traitement, et un peu de **Node.js** dès qu'un backend simple fait le job.

```
🔭 En ce moment      → j'améliore l'UX offline-first de Todo Planner
🌱 J'apprends        → animations avancées Flutter (Rive, Lottie custom)
💬 Demande-moi sur   → architecture d'app, offline-first, UI/UX mobile
⚡ Fun fact           → je passe autant de temps sur les micro-interactions que sur les features elles-mêmes
```
